Inventory management

Decides who manages player inventories when they enter arena and event worlds.

The plugin backs inventories up through InventoryBackup and restores them automatically after matches, events, deaths and disconnects. Multiverse-Inventories is not needed.
Legacy mode: Multiverse-Inventories handles the inventory swap. The plugin never restores on its own — if the world groups are missing or wrong, that is real item loss.
Safety backups Still copies every inventory through InventoryBackup before the arena/lobby teleport. Never restored automatically — an admin picks it up by hand if something goes wrong. Turning this off leaves legacy mode without any net of its own.
Automatic restore
After match end Gives the survival inventory back when a PvP match finishes Off: the inventory is still backed up, but never given back after a match. Players keep the kit until an admin restores it by hand.
After event end Gives the survival inventory back when an event finishes Off: participants leave the event with the kit. Their survival inventory stays in the backup until an admin restores it by hand.
After respawn Restores the inventory of a player who died in an arena Off: whoever dies in an arena respawns without their survival inventory. It only exists in the backup from then on.
On rejoin Restores the inventory of a player who disconnected mid-match Off: anyone who loses connection mid-match gets nothing back on their next join. Of the four switches this is the one that loses the most items.
"Continue and warn": matches start even when no backup reached the disk. The only remaining net is the in-memory copy, and it does not survive a server restart.
Delete backup after success Off keeps the backup as an archive On: the backup is deleted the moment the restore succeeds. If the restore put back the wrong state, there is no way back.
